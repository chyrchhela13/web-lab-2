Даниїл Кішик

Студент кібербезпеки у Львівській політехніці. Маю базові знання мережевих технологій, Python та SQL. Розглядаю стажування у сфері інформаційної безпеки.

01 / Компетенції

Ключові компетенції

Мережева інфраструктура Налаштування та діагностика мереж IP-адресація · Маршрутизація · DHCP
  • Розумію принципи взаємодії пристроїв у локальних мережах і призначення маршрутизаторів та комутаторів.
  • Розраховую IPv4-підмережі, налаштовую адресацію, статичні маршрути та автоматичне отримання мережевих параметрів через DHCP.
  • Перевіряю доступність вузлів, аналізую маршрут передавання пакетів і перевіряю мережеві налаштування під час пошуку несправностей.
Програмування Оброблення даних і розроблення API Python · ООП · HTTP API
  • Пишу програми на Python із використанням функцій, класів, колекцій та обробки винятків.
  • Працюю з текстовими файлами та JSON: зчитую, перевіряю, перетворюю дані й обчислюю зведені показники.
  • Створюю HTTP API на FastAPI, перевіряю вхідні дані та обробляю типові помилки запитів.
Бази даних Структурування та цілісність даних SQL · MySQL · SQLite
  • Створюю таблиці, добираю типи даних, визначаю первинні та зовнішні ключі.
  • Використовую обмеження цілісності для обов’язкових і унікальних значень та зв’язків між таблицями.
  • Пишу запити для додавання, вибірки, фільтрації та сортування даних.
