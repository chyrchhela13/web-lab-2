# Резюме Даниїла Кішика — лабораторна №4, React

Це готовий окремий React-проєкт. Його оформлення та текст відповідають останній HTML-версії.
GitHub є тільки у футері. Під заголовком відгуків немає пояснювального напису.

## 1. Куди покласти файли

Розпакуй архів. Усередині буде папка `lab_2_react`.
Поклади її в папку четвертої лабораторної:

```text
/Users/macintosh/Desktop/ЛАБИ/Веб-програмування/ЛАБА_4/lab_2_react
```

Поруч може залишатися папка `lab_4` зі звичайною HTML/CSS/JS-версією.
Якщо `lab_2_react` у цьому місці вже існує, спершу збережи її копію, потім поклади нову папку.
Архів містить весь проєкт: не потрібно розкладати компоненти вручну.

## 2. Як запустити

Потрібен Node.js 20.19+ або 22.12+ (підходить і новіша версія).

У терміналі виконай послідовно:

```bash
cd "/Users/macintosh/Desktop/ЛАБИ/Веб-програмування/ЛАБА_4/lab_2_react"
npm install
npm run dev
```

Відкрий адресу, яку покаже термінал:

```text
http://127.0.0.1:5174/
```

Для React запускай `npm run dev`, а не `python3 -m http.server` і не відкривай `index.html` подвійним кліком.
Поки переглядаєш сайт, залиш термінал із сервером відкритим. Зупинка — Ctrl + C.
Якщо порт 5174 зайнятий, зупини попередній сервер у його терміналі або виконай:

```bash
npm run dev -- --port 5175
```

Тоді відкрий `http://127.0.0.1:5175/`.

    ├── main.jsx               Запуск React і підключення провайдерів
    ├── App.jsx                Порядок секцій сторінки
    ├── index.css              Усе оформлення
    ├── config.js              Варіант 6, адреса Formspree, затримка форми
    ├── LanguageContext.jsx    Українська/англійська, збереження мови

        ├── Hero.jsx           Ім’я та короткий профіль
        ├── Experience.jsx     Компетенції
        ├── Skills.jsx         Технології та інструменти
        ├── Education.jsx      Освіта
        ├── Reviews.jsx        Отримання відгуків із сервера

Tailwind цьому проєкту не потрібен: оформлення знаходиться у `src/index.css`.

## 4. Що перевірити

1. Відгуки завантажилися. У `Reviews.jsx` запит виконується в `useEffect`, результат зберігається через `useState` і відображається через `.map()`.
2. У футері розкривається інформація про браузер і localStorage. Запис `browserInfo` створюється автоматично.
3. Через 60 секунд з’являється форма. Вона закривається кнопкою або Escape. Після закриття сама повторно не відкривається до перезавантаження сторінки.
4. Форма надсилає ім’я, email, телефон і повідомлення через ту саму адресу Formspree, яку вже перевірено у звичайній версії.
5. Кнопка із сонцем/місяцем змінює тему. Автоматично: світла з 07:00 до 21:00, темна — в інший час. Після ручного вибору автоматичне перемикання призупиняється до перезавантаження.
6. UK / EN у футері змінює мову інтерфейсу. Вибір зберігається після оновлення сторінки. Відгуки показуються мовою, якою їх повернув сервер.

React-версія працює на іншому порту, тому її localStorage окремий від версії на порту 8000 — це очікувано.
У режимі розробки StrictMode може показати додатковий скасований запит у Network. Активний запит працює, а попередній скасовується при очищенні ефекту.

## 5. Перевірка збірки

```bash
npm run build
```

Готова збірка з’явиться в `dist`. Для її локального перегляду:

```bash
npm run preview
```

Відкрий `http://127.0.0.1:4174/`.

## 6. Що показати у звіті

- React-сторінку з отриманими відгуками.
- Інформацію про браузер у футері та запис browserInfo в Application → Local Storage.
- Модальну форму та отриманий лист Formspree.
- Світлу й темну теми.
- Код компонентів Reviews, SystemInfo, ContactForm і ThemeProvider, де використовуються useState та useEffect.

`node_modules` і `dist` не потрібно додавати в Git: вони внесені до `.gitignore`.

- Окремо перевірено часові межі 07:00 і 21:00 та відображення українською й англійською.
- Надсилання листа з React автоматично не виконувалося; адреса Formspree збережена та сама, що вже працює у звичайній версії.
